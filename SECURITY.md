# Security reporting

Report a suspected vulnerability privately to [security@kooga.io](mailto:security@kooga.io). Say what is affected, what you expected and what happened, and how to reproduce it without real customer data.

Never post access tokens (`kooga_pat_...`), sign-in tokens, private keys or customer data in a public issue. If a Kooga access token was exposed, disconnect it at once in Kooga, at **Settings → Connected apps**, where it stops working immediately; then tell us privately.

This repository holds plugin manifests, registry metadata and workflow guidance for assistants. Kooga's hosted service handles sign-in, workspace permissions and everything the tools do. When you report, say whether the issue is in this packaging, in the guidance, or in the hosted service at `https://mcp.kooga.io/mcp`.
